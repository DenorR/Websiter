# Websiter — ИИ-конструктор сайтов

Клиент заходит на ваш сайт, **выбирает дизайн**, **описывает свой бизнес** — ИИ (Claude) анализирует его, пишет тексты, подбирает цвета и структуру, и тут же показывает готовый сайт. Дальше клиент может сменить дизайн или цвет в один клик, попросить ИИ о правках, скачать HTML-файл или поделиться ссылкой.

## Быстрый старт

```bash
npm install
cp .env.example .env      # впишите ANTHROPIC_API_KEY
npm start                 # http://localhost:3000
```

Нужен Node.js 20.12+. **Без ключа** сервис работает в демо-режиме: сайты собираются из встроенных заготовок (удобно посмотреть интерфейс). С ключом [Anthropic API](https://console.anthropic.com) тексты, структуру и цвета пишет ИИ.

```bash
npm test                  # 46 тестов, ключ не нужен
```

## Как это работает

```
Клиент ──► выбор дизайна ──► описание бизнеса ──► POST /api/generate (SSE: прогресс)
                                                        │
                      Claude: анализ + тексты + цвета + структура  (JSON по схеме)
                                                        │
                       нормализация и проверка ──► сохранение ──► шаблон дизайна ──► готовый сайт
```

Ключевая идея: **ИИ пишет не HTML, а структурированный контент (JSON)**, а внешний вид задаёт шаблон. Поэтому:

- дизайн и цвет меняются мгновенно, без повторного вызова ИИ (и без затрат);
- вывод модели не может сломать вёрстку или внедрить скрипт — весь текст экранируется;
- качество вёрстки одинаково хорошее, а ИИ занят тем, что умеет лучше всего — смыслом и текстами.

### Что делает ИИ

1. **Анализирует бизнес**: тип, аудитория, позиционирование, тон, сильные стороны (клиент видит это справа от превью).
2. **Выбирает структуру** под цель сайта (заявки / записи / продажи / информация): 4–6 секций из «О нас», «Услуги», «Как работаем», «Тарифы», «Вопросы», «Призыв».
3. **Пишет тексты** на языке описания (или на выбранном: ru, en, uk, de, es, fr).
4. **Подбирает фирменные цвета** под нишу и выбранный дизайн.
5. **Дорабатывает сайт по просьбе клиента** («сделай строже», «добавь вопросы в FAQ»).

### Честность контента

ИИ получил жёсткое правило: **не выдумывать** цены, отзывы, статистику, награды, годы опыта, адреса и телефоны. Блок «Тарифы» появляется только если клиент сам назвал цены. Контакты в сайт попадают только из формы клиента, а не от модели.

## Дизайны

| Дизайн | Характер | Подходит для |
|---|---|---|
| Минимал | чисто и воздушно | консультанты, студии, сервисы |
| Бизнес | надёжно и строго | компании, B2B, финансы, право |
| Тёмный | современно, технологично | IT, digital, гейминг |
| Тёплый | уютно, по-домашнему | кафе, пекарни, цветы, детские |
| Яркий | дерзко, заметно | креатив, фитнес, ивенты |
| Элегантный | премиально, сдержанно | салоны, ателье, ювелирка, рестораны |

Чтобы добавить свой, скопируйте любую тему в `src/render/themes.js` (палитра, шрифты, радиусы + небольшой блок CSS) — в интерфейсе она появится автоматически.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ API. Нет ключа — демо-режим |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | Модель. Для более быстрой и дешёвой генерации можно `claude-sonnet-5-5` |
| `ANTHROPIC_EFFORT` | `medium` | Глубина «раздумий»: `low` / `medium` / `high` |
| `PORT` | `3000` | Порт |
| `RATE_LIMIT_PER_HOUR` | `10` (демо: `100`) | Генераций в час с одного IP — защита вашего бюджета |
| `MAX_REVISIONS_PER_SITE` | `10` | Правок через ИИ на один сайт |
| `TRUST_PROXY` | выкл. | `1`, если сервис за nginx/Cloudflare — иначе лимит считается по IP прокси |
| `DATA_DIR` | `./data` | Где хранятся созданные сайты (JSON-файлы) |

## Структура проекта

```
server.js            запуск
src/app.js           HTTP-API (Express), SSE-прогресс, лимиты, CSP
src/ai.js            вызов Claude (structured outputs, стриминг) + демо-режим
src/schema.js        схемы: ввод клиента и контент сайта; нормализация ответа ИИ
src/mock.js          демо-генератор без ключа
src/render/          рендерер: иконки, темы, HTML страницы
src/store.js         хранилище сайтов (файлы)
src/ratelimit.js     лимитер запросов
public/              интерфейс конструктора (без сборки)
test/                тесты (node:test), включая фейковый Anthropic-сервер
```

## Что нужно знать при запуске в продакшене

- **Хранилище и лимиты рассчитаны на один процесс.** Сайты лежат в `DATA_DIR`, лимитер — в памяти. Для нескольких инстансов вынесите их в общую БД/Redis. Старые сайты автоматически не удаляются — при необходимости чистите папку по cron.
- **Nginx и потоки.** Прогресс идёт через Server-Sent Events; сервис уже отправляет `X-Accel-Buffering: no`, но если перед ним стоит свой прокси — отключите буферизацию для `/api/`.
- **Скачанный HTML** — один файл со стилями и скриптом внутри; шрифты подгружаются с Google Fonts (без интернета — системные).
- **Форма на сайте** открывает почтовый клиент (`mailto:`), так как у статичного сайта нет сервера для приёма форм. Для настоящей отправки подключите сервис форм.
- **Безопасность.** Ключ API живёт только на сервере. Сгенерированные страницы отдаются со строгим CSP и показываются в изолированном `iframe`; id сайтов — 80 бит случайности. Ввод клиента в промпте обрамлён тегами, их закрытие из текста невозможно.

## Идеи для развития

Свой домен и хостинг для сайтов, аккаунты и оплата, генерация картинок/логотипа, несколько страниц, приём заявок на сервере, более богатый редактор после генерации.
