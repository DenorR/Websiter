# Websiter — ИИ-конструктор сайтов

Клиент заходит на ваш сайт, **выбирает один из 18 дизайнов**, **описывает бизнес** — ИИ (Claude) анализирует его, пишет тексты и собирает страницу. Дальше клиент **настраивает всё до мелочей** в живом редакторе (цвета, шрифты, блоки, тексты, фото, контакты), скачивает готовый HTML-файл или делится ссылкой.

## Быстрый старт

```bash
npm install
cp .env.example .env      # впишите ANTHROPIC_API_KEY
npm start                 # http://localhost:3000
```

Нужен Node.js 20.12+. **Без ключа** сервис работает в демо-режиме: сайты собираются из встроенных заготовок (редактор и все дизайны работают полностью, только тексты шаблонные и нет правок через ИИ). С ключом [Anthropic API](https://console.anthropic.com) тексты, структуру и цвета пишет ИИ.

```bash
npm test                  # 124 теста, ключ не нужен
```

Посмотреть любой дизайн целиком, без регистрации: `http://localhost:3000/demo/noir`, `/demo/poster`, `/demo/vector` …

## Как это работает

```
Клиент ──► выбор дизайна ──► описание бизнеса ──► POST /api/generate (SSE: прогресс)
                                                        │
                      Claude: анализ + тексты + цвета + структура  (JSON по схеме)
                                                        │
              нормализация ──► сохранение ──► шаблон ──► живой редактор с предпросмотром
```

Ключевая идея: **ИИ пишет не HTML, а структурированный контент (JSON)**, а внешний вид задаёт шаблон. Поэтому:

- дизайн, цвета, шрифты меняются мгновенно, без повторного вызова ИИ (и без затрат);
- вывод модели не может сломать вёрстку или внедрить скрипт — весь текст экранируется;
- ИИ занят тем, что умеет лучше всего — смыслом и текстами, а вёрстка всегда выверена.

### Что делает ИИ

1. **Анализирует бизнес**: тип, аудитория, позиционирование, тон, сильные стороны.
2. **Выбирает структуру** под цель сайта (заявки / записи / продажи / информация): 4–7 блоков из «О нас», «Услуги», «Как работаем», «Цены», «Вопросы», «Манифест», «Призыв».
3. **Пишет тексты** на языке описания (или на выбранном: ru, en, uk, de, es, fr), расставляет выделения в заголовках.
4. **Подбирает фирменные цвета** под нишу.
5. **Рекомендует 2–3 дизайна** из каталога под этот бизнес (показываются в редакторе на вкладке «Дизайн»).
6. **Дорабатывает сайт по просьбе клиента** («сделай строже», «добавь вопрос про парковку»). Ручные настройки клиента при этом не теряются: скрытые блоки, выбранные раскладки, галерея, дизайн.

### Честность контента

ИИ получил жёсткое правило: **не выдумывать** цены, отзывы, статистику, награды, годы опыта, адреса и телефоны. Блок «Цены» появляется только если клиент сам назвал цены. Контакты попадают на сайт только из данных клиента. Демо-режим тоже ничего не выдумывает. (Демо-страницы дизайнов в каталоге содержат придуманные примеры — это витрина, не сайты клиентов.)

### Как добавить свой дизайн

Шаблон — это один файл-описание в `src/templates/` (палитры, шрифты, типографика, форма, раскладки блоков, стиль графики и небольшой блок CSS для «фирменных деталей»). Скопируйте любой существующий, поменяйте `id`, добавьте в `src/templates/index.js` и пример содержимого в `src/samples.js` — шаблон появится в каталоге и редакторе автоматически. Тесты (`test/templates.test.js`) проверят, что все шрифты, раскладки и палитры корректны.

## Редактор

Слева — вкладки, справа — живой предпросмотр (компьютер / планшет / телефон). Цвета, шрифты и стиль применяются **мгновенно, без перезагрузки**. Клик по блоку в предпросмотре открывает его тексты. Всё сохраняется автоматически; есть отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), страницу можно закрыть и вернуться по ссылке `#/site/<id>`.

| Вкладка | Что настраивается |
|---|---|
| **ИИ** | Анализ бизнеса, рекомендации дизайна, правки по просьбе («сделай строже») |
| **Дизайн** | Смена шаблона одним кликом (сброс настроек оформления — тексты остаются) |
| **Цвета** | Готовые палитры шаблона, «цвета ИИ», свои цвета (фон, текст, акцент, второй акцент) с проверкой контраста |
| **Шрифты** | 30 шрифтов с кириллицей: готовые пары или отдельный выбор для заголовков, текста и выделений; размеры, регистр и насыщенность заголовков |
| **Стиль** | Скругление (ползунок), форма картинок, кнопки (заливка/контур/подчёркивание, форма), карточки, отступы, ширина, иконки, шапки блоков, зерно, анимация, бегущая строка, графика (10 стилей) |
| **Блоки** | Порядок, показать/скрыть, **вариант вёрстки каждого блока** (у первого экрана — 6, у «Услуг» — 5 и т. д.), добавление блоков |
| **Тексты** | Каждый заголовок, абзац, пункт, иконка; выделение `*слов*` в заголовках |
| **Фото** | Логотип, фото первого экрана, фото «О нас», галерея до 12 фото |
| **Контакты** | Телефон, почта, адрес, часы, Telegram, WhatsApp, Instagram, VK, главная кнопка (форма / звонок / мессенджер) |
| **Ещё** | SEO-заголовок и описание, язык страницы, ссылка и скачивание |

С телефона редактор тоже работает: предпросмотр сверху, вкладки и настройки под ним.

### Шрифты и картинки — без внешних сервисов

Шрифты (`@fontsource`, только кириллица и латиница) отдаются **с вашего сервера** — никаких Google Fonts и CDN: сайты клиентов не зависят от чужих сервисов и работают в странах/сетях, где их нет. Скачанный HTML — **один файл**: шрифты и загруженные картинки встроены в него (base64).

Фото клиент загружает прямо в редакторе: браузер уменьшает их перед отправкой, сервер проверяет **содержимое** (JPG/PNG/WebP/GIF — SVG и всё остальное отклоняется), даёт случайное имя и хранит рядом с сайтом.

## Настройки (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ API. Нет ключа — демо-режим |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | Модель. Для более быстрой и дешёвой генерации можно `claude-sonnet-5-5` |
| `ANTHROPIC_EFFORT` | `medium` | Глубина «раздумий»: `low` / `medium` / `high` |
| `PORT` | `3000` | Порт |
| `RATE_LIMIT_PER_HOUR` | `10` (демо: `100`) | Генераций в час с одного IP — защита вашего бюджета |
| `MAX_REVISIONS_PER_SITE` | `10` | Правок через ИИ на один сайт |
| `TRUST_PROXY` | выкл. | `1`, если сервис за nginx/Cloudflare — иначе лимит считается по IP прокси |
| `DATA_DIR` | `./data` | Где хранятся сайты и загруженные фото |

Правки руками (цвета, шрифты, тексты, фото) ИИ не используют и ничего не стоят — лимит считает только вызовы Claude.

## Структура проекта

```
server.js               запуск
src/app.js              HTTP-API (Express): генерация (SSE), правки, загрузки, шрифты, CSP
src/ai.js               вызов Claude (structured outputs, стриминг) + демо-режим
src/schema.js           схемы: ввод клиента и контент сайта; нормализация ответа ИИ
src/model.js            модель сайта: оформление, контакты, медиа; «шаблон + настройки → переменные CSS»
src/templates/          18 шаблонов (по файлу на каждый)
src/render/             рендерер: варианты блоков (parts, variants), CSS, иконки
src/color.js            палитры: производные цвета, гарантия контраста
src/fonts.js            каталог шрифтов и @font-face (свои, из npm)
src/art.js              генеративная SVG-графика (10 стилей)
src/samples.js          примеры сайтов для каталога дизайнов
src/mock.js             демо-генератор без ключа
src/store.js, uploads.js, export.js, ratelimit.js
public/                 интерфейс конструктора и редактора (без сборки)
test/                   тесты (node:test), включая фейковый Anthropic-сервер
```

## Что нужно знать при запуске в продакшене

- **Хранилище и лимиты рассчитаны на один процесс.** Сайты и фото лежат в `DATA_DIR`, лимитер — в памяти. Для нескольких инстансов вынесите их в общую БД/объектное хранилище и Redis. Старые сайты не удаляются автоматически — при необходимости чистите папку по cron.
- **Диск.** Каждый сайт — до 24 загруженных файлов по 6 МБ; при необходимости ужесточите `MAX_UPLOAD_BYTES` / `MAX_FILES_PER_SITE` в `src/uploads.js`.
- **Права доступа.** Сайт доступен по ссылке с 80-битным случайным id (как «доступ по ссылке» в облачных документах). Аккаунтов пока нет: кто знает ссылку, тот может редактировать. Для публичного сервиса добавьте авторизацию.
- **Nginx и потоки.** Прогресс идёт через Server-Sent Events; сервис отправляет `X-Accel-Buffering: no`, но если перед ним стоит свой прокси — отключите буферизацию для `/api/`.
- **Форма на сайте** открывает почтовый клиент (`mailto:`), так как у статичного сайта нет сервера для приёма форм. Для настоящей отправки подключите сервис форм или добавьте обработчик.
- **Безопасность.** Ключ API живёт только на сервере. Сайты отдаются со строгим CSP (`default-src 'none'`, шрифты и картинки только с вашего домена) и показываются в `iframe` с песочницей. Весь текст экранируется, ссылки на картинки принимаются только на собственные загрузки, ввод клиента в промпте обрамлён тегами, закрыть которые из текста нельзя.

## Идеи для развития

Свой домен и хостинг для сайтов клиентов, аккаунты и оплата, генерация картинок и логотипа, несколько страниц, приём заявок на сервере, больше шаблонов и блоков (отзывы — когда клиент сам их введёт, карта, прайс-таблицы).
